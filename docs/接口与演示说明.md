# 接口与演示说明

## 管理端接口

- `POST /api/auth/login`：管理员登录。
- `GET /api/admin/statistics/today`：今日经营数据。
- `GET /api/admin/dishes`：菜品列表。
- `POST /api/admin/dishes`：新增菜品。
- `PUT /api/admin/dishes/{id}`：修改菜品。
- `GET /api/admin/orders`：全部订单。
- `PUT /api/admin/orders/{id}/status/{status}`：订单状态流转。

## 用户端接口

- `POST /api/user/auth/demo-login`：演示用户登录。
- `GET /api/user/categories`：在用分类。
- `GET /api/user/dishes?categoryId=1`：在售菜品。
- `GET/POST/DELETE /api/user/cart`：购物车。
- `GET /api/user/addresses`：地址列表。
- `POST /api/user/orders`：提交订单。
- `GET /api/user/orders`：用户订单。
- `POST /api/user/orders/{id}/mock-pay`：模拟支付。

完整结构和在线调试以 Swagger UI 为准。

## 推荐演示流程

1. 启动基础设施、后端和两个前端。
2. 商家端使用默认管理员登录，展示菜品和经营概览。
3. 小程序选择分类并将两个菜品加入购物车。
4. 提交订单并模拟支付。
5. 商家端收到 WebSocket 提醒并刷新订单。
6. 依次执行接单、制作完成、开始配送和完成。
7. 小程序订单页重新进入后展示最新状态。
8. 用同一 `clientOrderNo` 重复提交，说明服务端幂等设计。
9. 创建订单后不支付，展示 RabbitMQ 超时关单设计（演示时可临时缩短队列 TTL）。
