# 云膳外卖运行手册

## 1. 环境要求

- JDK 17
- Maven 3.9+
- Node.js 22+
- Docker Desktop 或兼容的 Docker Engine
- 微信开发者工具（运行微信小程序时）

## 2. 启动基础设施

在项目根目录执行：

```powershell
docker compose -f deploy/docker-compose.yml up -d
```

默认端口：

| 服务 | 端口 | 账号 |
|---|---:|---|
| MySQL | 3306 | `cloud_meal/cloud_meal_dev` |
| Redis | 6379 | 无密码，仅本地开发 |
| RabbitMQ | 5672、15672 | `cloud_meal/cloud_meal_dev` |
| MinIO | 9000、9001 | `cloudmeal/cloudmeal_dev_password` |

## 3. 启动后端

```powershell
mvn -pl cloud-meal-server spring-boot:run
```

- 接口根地址：`http://localhost:8080/api`
- OpenAPI：`http://localhost:8080/api/swagger-ui.html`
- 健康检查：`http://localhost:8080/api/actuator/health`

Flyway 首次启动自动创建数据库表和演示数据。默认管理员：

```text
账号：admin
密码：Admin@123456
```

## 4. 启动商家管理端

```powershell
cd cloud-meal-admin
npm install
npm run dev
```

访问 `http://localhost:5173`。Vite 会把 `/api` 和 WebSocket 请求代理到后端。

## 5. 启动 uni-app 用户端

```powershell
cd cloud-meal-user
npm install
npm run dev:mp-weixin
```

使用微信开发者工具导入 `cloud-meal-user/dist/dev/mp-weixin`。首次本地演示可关闭域名校验；真实发布必须配置备案 HTTPS 域名，并把 `src/manifest.json` 中的微信 AppID 和请求生产地址替换为真实值。

用户端点击加入购物车时会自动使用演示用户登录。模拟支付用于完成无商户号条件下的订单闭环。

## 6. 一键容器化运行

```powershell
docker compose -f deploy/docker-compose.full.yml up -d --build
```

完成后访问：

- 商家端：`http://localhost`
- 后端：`http://localhost:8080/api`

## 7. 测试和构建

```powershell
mvn test
cd cloud-meal-admin
npm run build
cd ../cloud-meal-user
npm run build:mp-weixin
```

## 8. 常见问题

### 后端无法连接数据库

检查 Docker Desktop 是否启动，并执行 `docker compose -f deploy/docker-compose.yml ps`。MySQL 第一次初始化需要一定时间。

### RabbitMQ 连接失败

打开 `http://localhost:15672` 检查服务。下单依赖延迟消息，RabbitMQ 不可用时事务会回滚，这是为了避免产生无法自动关闭的订单。

### 微信小程序请求失败

微信开发者工具中关闭开发阶段的合法域名校验，或者使用真实 HTTPS 域名。真机不能使用电脑的 `localhost`，需要配置局域网地址或公网测试域名。

### 前端出现401

清除浏览器或小程序本地缓存后重新登录。JWT 默认有效期2小时。
